# Introduction to Proofs

Starter repository for the **Study Platform — Introduction to Proofs** project.

## Goal
Practise fundamental methods used to construct and understand mathematical proofs.

## Suggested topics
- Statements and predicates
- Direct proofs
- Proof by contradiction
- Contrapositive
- Mathematical induction
- Counterexamples
- Basic set and logic notation

## Getting started
```bash
git clone <your-fork-url>
cd math-intro-proofs-template
```
